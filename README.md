# Void Pointer with typedef

## Author
M.Likitha

## Description
This program demonstrates using a void pointer with a
user-defined type created using typedef.

A Record structure is created using typedef. Its address
is stored in a void pointer and passed to a function.
The function converts the void pointer back to Record *.

## Concepts Used
- Void pointer
- typedef
- Structure
- User-defined data type
- Type casting
- Function parameter

## How to Run

gcc void_pointer_typedef.c -o void_pointer_typedef

./void_pointer_typedef
